# Input
Interfacing with games is difficult.
Developers need to think about the method of input (gamepad,mouse,keyboard)
As well as handle different button and joystick layouts binding for all game actions
## Input System
Unity has a package called **input system** which you can install via the Window Package Manager
This allows you to add a input action file, the input action file allows you to easily create bindings for inputs in your game. As well as allow you to set inputs for multiple interfaces

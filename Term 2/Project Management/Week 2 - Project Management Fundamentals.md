# 5 Project Management Processes (PMI)
## Initiating
Defines a new project (or new phase of an existing project) by obtaining authorization to start the project (or phase)

**Purpose**
- Align stakeholder's expectations with the project's purpose
- Give stakeholder visibility about the project's scope and objectives
- Show stakeholders how their participation can ensure their expectations are achieved
**Activities**
- Initial scope is defined
	- Initial financial resources are committed
- Internal and external stakeholders are identified
